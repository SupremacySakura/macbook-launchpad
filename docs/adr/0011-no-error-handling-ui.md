# V1 不显示错误 UI：启动失败和图标加载失败都静默处理

V1 在以下两种失败场景下**不显示任何错误提示**：
1. 点击应用项启动失败（权限不足、应用损坏）→ 静默失败
2. 应用图标加载失败（`NSWorkspace.icon(forFile:)` 返回 nil）→ 使用系统默认应用图标

理由：
- 这两种失败概率都极低（能被扫描到的应用通常能启动，几乎所有 `.app` 都有图标）
- 显示错误对话框需要处理"用户点确定后是否退出启动台"等状态分支，复杂度高
- 用户发现应用没启动会自己再点一次；看到默认图标至少知道应用存在

后果：
- 用户可能因为"点击没反应"而困惑。如果成为高频反馈，V2 可以加 Toast 提示
