# 固定 8×5 网格，不做自适应布局

启动台网格固定为 8 列 × 5 行 = 40 个应用项一屏，每格 152×152pt（图标 128pt + 名称），水平间距 24pt、垂直间距 8pt。超过 40 个应用时垂直滚动，不做水平分页。

理由：
- macOS 15 原生 Launchpad 在 13" 屏幕是 7×5，15" 是 8×5，取上限在小屏幕上也不会拥挤
- 固定网格比自适应简单：不用处理窗口 resize（反正全屏）、不用做响应式布局
- 垂直滚动比水平分页更符合现代用户习惯（参考 iOS App Library、macOS 26 App Library）

后果：
- 与原生 Launchpad 的"水平分页"视觉不同。这是一个有意的偏离，因为水平分页的 PageControl 在触控板上手感差
