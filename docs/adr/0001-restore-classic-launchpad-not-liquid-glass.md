# 恢复经典 Launchpad，而非模仿 macOS 26 Liquid Glass

macOS 26 (Tahoe) 移除了经典 Launchpad，改用 App Library + 全新 Spotlight。本项目的目标是**复刻被移除的经典 Launchpad 体验**——深色模糊背景、图标网格、按压放大动画——而不是在 macOS 26 上用 Liquid Glass 风格重新设计一个 Launcher。

这决定了：
- 视觉参考是 macOS 15 (Sequoia) 及更早版本的 Launchpad，不是 macOS 26 的任何系统 UI
- 不使用 Liquid Glass 的 Squircle 图标形状、半透明材质、新动画曲线
- 项目存在的前提是"用户怀念旧 Launchpad"，如果用户想要 Liquid Glass 风格，应直接使用系统自带 Spotlight
