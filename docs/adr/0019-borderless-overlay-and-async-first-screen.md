# 用无边框覆盖层替代系统全屏，并异步加载首屏

Status: accepted

启动台不再调用 `toggleFullScreen` 创建独立 Space，而是在当前活动显示器上显示无边框覆盖窗口，并隐藏菜单栏与 Dock。覆盖窗口的界面边距会显式加上目标屏幕的安全区，避免搜索框等内容进入刘海或摄像头区域。应用元数据在后台全量扫描，图标只按当前页与相邻页加载。原因是系统全屏过渡、同步扫描和全量图标加载叠加后占据了首屏的大部分等待时间。代价是启动台不再出现在 Mission Control 的 Spaces 中，且首屏出现后图标可能短暂按页补齐；这不改变“每次启动重新扫描、不做持久化缓存”的既有决定。
