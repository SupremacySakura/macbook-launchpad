# 先做技术验证原型，再开始正式开发

在写正式代码前，先做一个最小原型（< 50 行代码）验证三个关键技术点：
1. `NSVisualEffectView` 在 macOS 26 全屏效果是否正常
2. `NSWorkspace.icon(forFile:)` 能否正确加载第三方应用图标
3. 全屏窗口能否正确响应 `Esc` 键退出

理由：
- 这三个是项目成败的关键技术点，任何一个失败都会导致项目无法实现
- 原型只需 1-2 小时，能避免"写了 1000 行代码才发现全屏 API 不工作"的浪费
- 原型代码可以直接丢弃，不影响正式代码质量

验证通过标准：
- 全屏窗口能正常显示模糊背景
- 能看到至少一个应用的图标
- 按 `Esc` 能退出应用
