# V1 测试策略：仅单元测试核心逻辑，不做 UI 测试

V1 只为 `AppScanner` 和搜索过滤逻辑写单元测试，不编写 UI 测试或 snapshot 测试。

测试场景：
- `AppScanner` 能在测试 fixtures 中找到 `.app`
- 搜索过滤：输入子串能正确匹配/排除应用

明确**不做**：
- ❌ XCUITest（启动全屏应用、模拟键盘输入、点击图标）——太慢，且 V1 UI 迭代频繁
- ❌ SwiftUI snapshot 测试——V1 视觉还在快速变化

理由：
- V1 的核心价值在"能扫描、能过滤、能启动"，这些是纯逻辑，单元测试覆盖足够
- UI 测试的运行时间（分钟级）远超单元测试（毫秒级），拖慢迭代

后果：
- UI 层的 bug（如布局错乱、动画异常）只能靠手动测试发现
- 如果 V2 加入复杂交互（拖拽、文件夹），需要补 UI 测试
