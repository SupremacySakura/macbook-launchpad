# V1 动画：仅 fade-in 和点击放大，不做复杂过渡

V1 只实现两个动画：
1. **打开时**：整个窗口从透明到不透明（fade in），0.2 秒
2. **点击应用项时**：图标短暂放大 1.1 倍（0.1 秒）再恢复，然后启动应用并退出

明确**不做**：
- ❌ 图标从 Dock 飞入的抛物线动画
- ❌ 搜索时应用项的淡入淡出过渡
- ❌ 鼠标 hover 时的图标放大（原生 Launchpad 没有此效果）

理由：
- 抛物线动画需要操作窗口层级和 Dock 私有 API，复杂度高且容易在新 macOS 版本失效
- 搜索过滤时直接重新布局比平滑过渡简单得多；用户在输入时关注的是结果，不是动画
- V1 的核心是"能用"，不是"炫技"

后果：
- 视觉上会比原生 Launchpad "朴素"。如果用户反馈"不像原生"，V2 再加过渡动画
