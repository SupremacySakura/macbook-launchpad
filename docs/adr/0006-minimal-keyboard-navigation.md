# V1 键盘导航：仅搜索框 + Enter 启动，不做方向键

V1 的键盘交互模型：
- 应用打开后搜索框自动聚焦
- 输入字符实时过滤
- 按 `Enter` 启动第一个匹配的应用
- 按 `Esc` 清空搜索；搜索为空时再按 `Esc` 退出应用
- 不实现方向键在图标间移动焦点

理由：
- 真实用户路径是"打开 → 输入 → Enter"，方向键导航是低频操作
- 方向键导航需要实现焦点环、选中态视觉、键盘焦点与鼠标 hover 的冲突处理，复杂度高
- macOS 26 原 Launchpad 用户中，鼠标/trackpad 用户远多于纯键盘用户

后果：
- 纯键盘用户（不习惯用鼠标）会觉得 V1 不可用。如果这是一个真实用户群，V2 优先做方向键导航
