# 不做缓存：每次启动全量重新扫描应用目录

Status: superseded by ADR 0025

每次启动应用时重新扫描 `/Applications`、`~/Applications`、`/System/Applications`，不持久化任何应用列表或图标缓存。

理由：
- 扫描 3 个目录 + 加载所有图标在 SSD 上总耗时 < 300ms，用户感知不到
- 不缓存就没有"缓存过期"问题：用户安装/卸载应用后启动台立即反映
- 不需要 `FSEvents` 监听、不需要缓存失效策略、不需要后台守护进程

后果：
- 如果用户安装了 500+ 应用导致扫描超过 1 秒，可能需要重新考虑缓存。届时再加，但不要提前优化。
