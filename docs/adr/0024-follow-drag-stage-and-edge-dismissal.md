# 中央翻页舞台、四周边界退出与跟手分页

Status: accepted; supersedes ADR-0022

窗口交互以一个“翻页舞台”为中心：左右各留出 `56pt`、底部留出 `64pt` 的退出带，顶部从网格上缘开始，舞台内的空白区域不退出并支持横向拖动翻页；点击舞台外的空白边缘会立即退出。配色按交互角色分工：近黑墨蓝画布托住内容，翻页舞台使用低饱和冷青玻璃，退出带使用更深的钴蓝，并以薄荷青到电光蓝的单条渐变描边划清边界；薄荷青只用于当前页和输入光标。搜索框、应用项和页面指示器等可交互内容始终优先于退出带，拖动一旦从舞台内开始，即使指针越过边缘也继续归翻页手势所有，避免翻页时误退出。

鼠标拖动期间页面实时跟手，第一页和最后一页使用阻尼回弹；松手后结合拖动距离与预测速度决定目标页，并用 `400ms` 的无弹跳缓出曲线落位。触控板继续使用系统原生分页惯性和系统滚动行为，但页面指示器使用同一套视觉节奏。这样保留了四周边界快速退出的直接感，同时解决了原先松手后才整页跳动造成的迟滞与卡顿。
