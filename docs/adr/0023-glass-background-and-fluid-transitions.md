# 深色玻璃背景与短促、可退出的界面动效

Status: accepted; paging motion amended by ADR-0024

背景由无色调的系统材质改为“深色玻璃”：保留桌面模糊材质，在上面叠加近黑墨蓝基底、右上角的电光钴蓝扩散和左下角极弱的薄荷青反光，并用边缘暗角把应用图标和搜索框留在视觉中心。打开时窗口在 220ms 内淡入，前景从 0.992 倍轻微放大到原始尺寸；关闭时前景和背景在 200ms 内淡出并轻微收束，动画完成后再终止进程。程序化翻页使用 260ms 的强 ease-out 曲线，保留触控板原生滚动；所有位移和缩放动画在“减弱动态效果”开启时改为更短的透明度过渡。这样可以让全屏覆盖层有明确的空间层次和进入/退出连续性，同时避免使用大幅缩放、弹跳或影响高频操作的动画。
