# V1 范围：仅"打开 + 搜索"，明确排除高级特性

Status: partially superseded by ADR 0020 and ADR 0021

V1 版本只做两件事：展示应用、按名称搜索并启动。明确**不做**以下功能，把它们推迟到 V2+：

- ❌ 拖拽排序
- ❌ 文件夹（把多个应用归为一组）
- ❌ 多页水平滚动（V1 用垂直滚动处理溢出）
- ❌ Dock 集成 / 全局快捷键唤起
- ❌ 卸载应用
- ❌ 拼音搜索（如 "wx" 匹配"微信"）

理由：
- 这些功能每一个都显著增加复杂度（拖拽需要 `NSDraggingSession`、文件夹需要数据模型扩展、拼音需要中文分词库）
- V1 的核心价值是验证"应用扫描 + 网格渲染 + 搜索过滤"这条主链路
- 把 V2 范围写在 ADR 里，是为了避免开发中"顺手加上"导致 V1 失控

后果：
- 如果用户反馈"没有拖拽/文件夹根本不能用"，V2 优先级会提前
- V1 上线后收集真实使用反馈，再决定 V2 做什么
